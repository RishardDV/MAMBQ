# Landing Page

La landing page es el sitio web público del museo, desplegado en **GitHub Pages**. Es una página estática construida con HTML, CSS y JavaScript vanilla, separada de la aplicación PWA.

**URL:** [risharddv.github.io/MAMBQ](https://risharddv.github.io/MAMBQ/)

---

## Hero principal

Presenta el nombre del museo, su descripción institucional y dos botones de acceso: **Descargar app** (instalación PWA) y **App Online** (acceso directo a la aplicación en Render).

![Landing — hero principal](pathname:///MAMBQ/img/app/landing1.png)

---

## Sección de artistas

Muestra la galería de artistas destacados del MAMB con fotografía, fechas, reseña biográfica y etiquetas temáticas. Entre los artistas incluidos: Álvaro Cepeda Samudio, Alejandro Obregón y Enrique Grau.

## Despliegue

La landing se sirve directamente desde la carpeta `Landing MAMB/` en la rama `main` del repositorio. GitHub Pages la publica automáticamente en cada push.

```bash
# Para probar localmente
cd "Landing MAMB"
npx http-server
```
