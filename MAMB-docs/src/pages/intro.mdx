# Museo de Arte Moderno de Barranquilla (MAMB)

![Landing del proyecto](/img/app/landing1.png)

## Descripción General

MAMB es una aplicación web desarrollada para el Museo de Arte Moderno de Barranquilla con el objetivo de fomentar la creatividad y la participación artística de niños y visitantes.

La plataforma permite compartir obras de arte, explorar galerías virtuales, participar en actividades interactivas y descubrir información relacionada con el arte de manera dinámica y educativa.

## Objetivos

El proyecto busca:

- Incentivar la creatividad infantil.
- Facilitar la exposición de obras artísticas.
- Crear una experiencia digital interactiva.
- Acercar el museo a nuevas audiencias.
- Promover el aprendizaje mediante actividades lúdicas.

## Componentes del Sistema

El sistema está compuesto por tres módulos principales:

### Landing Page

Sitio web informativo donde los visitantes pueden conocer el museo, artistas destacados y acceder a la aplicación principal.

### Aplicación Web (PWA)

Aplicación principal donde los usuarios pueden:

- Explorar galerías.
- Subir obras.
- Participar en juegos.
- Gestionar perfiles.
- Interactuar con obras mediante likes y calificaciones.

### Backend

API REST encargada de:

- Gestión de usuarios.
- Gestión de obras.
- Moderación de contenido.
- Calificaciones.
- Almacenamiento de información.

| Tecnología | Uso |
|------------|-----|
| HTML5 | Estructura de interfaces |
| CSS3 | Diseño visual |
| JavaScript | Lógica del sistema |
| Node.js | Backend |
| Express | API REST |
| PostgreSQL | Persistencia de datos |
| TensorFlow | Procesamiento IA |
| PWA | Instalación y uso offline |

## Características Principales

- Galería virtual.
- Subida de obras.
- Juego de memoria.
- Sistema de likes.
- Sistema de calificaciones.
- Filtros de búsqueda.
- Perfiles de usuario.
- Compatibilidad móvil.
- Aplicación instalable (PWA).
